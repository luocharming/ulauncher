# thingue.launcher 修改需求

## 1. 连接断开 IP 展示与剔除（图1）

- 在实例列表每个实例中增加一列“IP”列表展示。（当前实例所有已连接客户端的ip地址）；
- 列表中的每个 IP 后面带一个 “X” 断开键，点击“X”可断开连接；
- 同样支持一键全断开；
- 所有客户端都被断开后，连接数为0，对应实例变为未分配状态（与第 5.1 节联动）。

## 2. 实例白名单

- 每个实例支持配置白名单，点击实例`设置`按钮后，在设置面板上进行白名单配置；
- 白名单可添加一个或多个 IP，也可以不添加;
- 未配置白名单的则不做白名单条件筛选；
  
## 3. 实例类型与连接数

- **独占实例**：连接数固定为 1。
- **共享实例**：
  - 默认连接数为 -1，表示连接数不受限；
  - 可以手动设置共享实例的连接数个数，配置方法同`实例白名单`，点击实例`设置`按钮之后，在设置面板上配置连接数上线；

## 4. 客户端请求参数

- 客户端请求连接时，可以携带参数，标识本次请求是**独占实例**还是**共享实例**。
- 目前是通过 `D:\unreal\projects\uino\thinguelib` 基于PixelStreaming-Frontend封装的客户端拉流SDK，同步修改其中的代码，用于支持传入独立还是共享字段；

## 5. 实例分配策略

### 5.1 独占实例分配

1. 先从独占实例中筛选：
   - 如果独占实例配置了白名单，且白名单包含该客户端 IP，且该实例未被占用，则分配给该实例。
   - 如果独占实例配置了白名单，但白名单不包含该客户端 IP，则按顺序从**没有配置白名单**的独占实例中选择未被占用的实例分配。
2. 如果所有独占实例都已被占用，则不分配实例。

### 5.2 共享实例分配

1. 先从配置了白名单的共享实例中筛选：
   - 如果共享实例配置了白名单，且白名单包含该客户端 IP，且共享实例连接数未满，则分配给该实例。
2. 如果所有共享实例的白名单都不包含该客户端 IP，则按顺序从**没有配置白名单**的共享实例中选择顺序最靠前的实例：
   - 如果最靠前的实例连接数已满（实际连接数 == 共享实例设置的连接数），则按顺序查找下一个共享实例；
   - 直到找到可分配的共享实例，或所有共享实例都已分配满为止。
